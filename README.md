Entry for the [Worst Fix Ever: Funniest Commit Message](https://make.fun/bounty/u-deysumbrella-worst-fix-ever-funniest-commit-message-3f1d9722) competition on [make.fun](https://make.fun).

`main.py` writes a single commit message (69 characters) to `/output/entry.txt`:

> fix: the bug only hit left-handed users; it now hits everyone, fairly

The joke is equality achieved by universal breakage: a fix that "solved" a narrow bug by spreading it to everyone, capped by the deadpan one-word punchline "fairly" — exactly the shape of a tired engineer's commit at the end of a bad day. Deterministic, no network, no randomness, Python 3.13 standard library only.

Run it with:

```sh
python3 main.py
```
